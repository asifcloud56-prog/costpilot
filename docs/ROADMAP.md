# Roadmap (12 months)

- [x] **Month 1-2**: Cluster, Prometheus, Grafana, OpenCost, demo app (the starter repo)
- [ ] **Month 3-5**: Data collection: load tests and public cluster traces (Google/Alibaba)
- [ ] **Month 6-8**: Right-sizing model (ML) and a pull-request cost bot (GitHub Action)
- [ ] **Month 9-10**: Kyverno guardrails, idle-environment auto-shutdown, before/after measurement
- [ ] **Month 11-12**: Open-source release, blog posts and a public benchmark report

## Every month

1. Record the numbers (cost, utilization, savings) in `docs/results.md`
2. Publish one LinkedIn post: what was built, what was learned, with a graph
3. Keep committing regularly
